## Recurrence Lab (`recurrence/index.html`) An inference workbench for draw-style number series, reachable from the sidebar of the main app. It answers one question honestly: **is the recurrence you see a derivable law, chance, or a mixture?** Paste any history (one draw per line; dates, separators and `|`/`+` bonus columns are handled), set the pool and picks per draw, and the lab runs five checks against the null hypothesis of exchangeable sampling without replacement, then routes you to the tool the evidence justifies. | Tool | Used when | What it does | | --- | --- | --- | | 1. Analytic derivation | Pattern detected | Searches a restricted class of closed-form recurrences (constant, arithmetic, affine mod M, second-order linear mod M, periodic, polynomial) and reports a law **only if it survives out-of-sample validation**, selected by minimum description length. | | 2. Stochastic recurrence | No pattern detected | Beta-Binomial posterior per number with the prior centred on the hypergeometric rate q = k/N, FDR-controlled deviation tests, credible intervals, and a gap analysis that quantifies the gambler's fallacy. | | 3. Hybrid ensemble | Mixed pattern | Four experts (null, shrunk frequency, adaptive EWMA, analytic law) compete under log loss; multiplicative weights learn the mixture online. The learned weights measure how much is structure and how much is chance. | All three tools stay selectable at all times — the routing is a recommendation, not a lock. **Guardrails.** The hypothesis class is restricted to explicit assumptions about the generating process; conclusions are probabilistic, never certain; prior knowledge (sampling without replacement, q = k/N) supplies the inductive bias so far less data is needed; and every model is judged by walk-forward prediction of unseen draws, never by its fit to history. If a model cannot beat the uniform baseline out of sample, the lab says so plainly — which is the correct and expected result for a fair lottery. Verified behaviour: on 30 independent pure-chance corpora the lab reports "no pattern", finds no law, and declines to claim an edge; on planted-bias and deterministic corpora it recovers the bias and the exact recurrence. ## Current workflow - Internal dashboard for operating status. - Business Blueprint generator. - Ads and affiliate promotion planner. - Canvas output document with local state and text export. - Demo login modal using `demo@readi4bizness.com` and `readi-demo-2026`. - Recurrence Lab for law-vs-chance inference on number series.
